MAUA Privacy Policy

MAUA is a Discord bot used for moderation, verification, reports, safety tools, warnings, quarantine actions, direct-message support, and server administration inside Modded Among Us Lobbies and related community workflows.

Privacy Contact Retention Details

Policy At A Glance

MAUA only processes Discord information needed to operate server features, protect members, support staff, and keep records that help prevent abuse.

Verification

MAUA may process Discord IDs, roles, join dates, verification status, and submitted answers.

Moderation

Warnings, punishments, bans, staff notes, reports, and quarantine records may be stored.

Messages

Message content is used only when needed for commands, reports, logging, safety, or moderation.

Access Limits

Bot records are limited to authorized staff, bot maintainers, and administrators with a need to know.

Information We Collect

MAUA may collect or process the following Discord information only when needed for enabled bot features.

Discord Account And Server Data

  • Discord user IDs, usernames, display names, avatars, mentions, and server nicknames.
  • Server IDs, channel IDs, thread IDs, role IDs, message IDs, command IDs, and interaction IDs.
  • Member role information, join dates, verification status, and access eligibility.

Moderation And Safety Records

  • Warnings, bans, mutes, quarantines, punishments, reports, staff notes, and appeal history.
  • Evidence or context voluntarily submitted through reports, forms, direct messages, or commands.
  • Emergency or safety-tool submissions when a user or staff member uses those workflows.

Message And Command Data

  • Command usage, command arguments, form submissions, button/menu interactions, and timestamps.
  • Message content, embeds, attachments, or links when needed for moderation, reports, logs, or bot commands.
  • Direct messages sent to MAUA when users contact the bot or use DM-based support features.

What MAUA Does Not Collect

  • MAUA does not collect Discord passwords, private tokens, payment information, or unrelated account credentials.
  • MAUA does not intentionally collect data from servers where the bot is not installed or has no access.
  • MAUA does not sell collected user data.

How Information Is Used

Bot Operation

Information is used to run commands, verify users, manage roles, answer support requests, process reports, send notices, maintain bot configuration, and troubleshoot bugs.

Moderation And Safety

Information may be used to investigate reports, enforce server rules, identify abuse patterns, prevent spam, reduce ban or punishment evasion, and protect community members.

Staff Review

Authorized staff may review MAUA records when making moderation, verification, appeal, safety, or administrative decisions.

Reliability

Logs and command metadata may be used to debug errors, audit bot behavior, recover failed actions, and keep moderation or verification workflows accurate.

Discord Gateway Intents

MAUA may use Discord gateway intents so Discord can send events required for moderation, verification, commands, reports, logging, role checks, member safety, and administrative workflows.

Message Content Intent

Used when message text, embeds, attachments, or command arguments are needed for prefix commands, moderation tools, report handling, deletion tools, warning systems, verification flows, support workflows, safety reports, or staff logs.

Server Members Intent

Used to read member join, leave, update, role, nickname, and profile events needed for verification, access control, quarantine, warnings, moderation actions, role management, and user lookup tools.

Presence Intent

MAUA only uses presence data if an enabled feature requires it. If used, presence or activity data is limited to bot functionality and is not sold, profiled for advertising, or shared with unrelated third parties.

Default Discord Events

MAUA also processes normal Discord events where it has permission, including channels, threads, roles, messages, reactions, interactions, invites, and voice state events needed for server tools.

Sharing And Disclosure

No Sale Of Data

MAUA does not sell user data, use collected data for third-party advertising, or share collected data with unrelated third parties.

Authorized Staff

Data may be visible to authorized server staff, bot owners, maintainers, or administrators when needed for moderation, safety, appeals, support, troubleshooting, or bot operation.

Service Providers

Data may be processed by Discord and by hosting, database, logging, or infrastructure providers used to run MAUA. Providers are used to operate bot features, not to sell user data.

Normal Server Visibility

Some output may be visible in server channels as part of normal bot behavior, such as verification prompts, moderation notices, report acknowledgements, role panels, or staff logs.

Storage, Retention, And Deletion

Storage

MAUA data may be stored in local databases, MySQL databases, SQLite databases, configuration files, logs, or other storage used to operate the bot.

Retention

Data is kept only as long as needed for bot functionality, server administration, moderation history, safety, audit logs, abuse prevention, troubleshooting, or legal/security reasons.

Deletion Requests

Users may request access, correction, or deletion of eligible personal data. Requests should include the user's Discord ID so the correct records can be located.

Limits On Deletion

Some records may be retained when deletion would affect active investigations, moderation history, abuse prevention, ban evasion tracking, unresolved disputes, audit logs, or server security.

Security And Updates

Security

Reasonable steps are taken to restrict MAUA data to authorized people and protect stored records. No online system can guarantee perfect security.

Children's Privacy

MAUA is intended for use on Discord and follows Discord's age requirements. MAUA is not intended to knowingly collect information from children under the age required to use Discord.

Policy Changes

This Privacy Policy may be updated as MAUA, Discord requirements, server workflows, or applicable rules change. Continued use of MAUA after updates means the revised policy applies.
