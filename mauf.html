What The Bot Does

Modded Among Us Mafia is a Discord community bot used to run and manage the Mafia systems that were previously handled by the Modded Among Us Games bot.

Mafia Game Management

The bot supports Mafia setup, player joining, host controls, role assignment, private game channels or chats, game logs, voting, night actions, points, stats, mutes, warnings, FAQ panels, and staff review workflows related to Mafia games.

Server-Only Use

The bot is intended for Modded Among Us Lobbies and related Mafia workflows. It is not a public multipurpose bot, and it is not used to sell user data or serve advertising.

Information We Collect

The bot only collects or processes Discord information needed for enabled Mafia features, server administration, support, safety, and troubleshooting.

Discord Account And Server Data

  • Discord user IDs, usernames, display names, avatars, and mentions.
  • Server IDs, channel IDs, thread IDs, role IDs, message IDs, and application IDs.
  • Member role information and permissions when needed for Mafia hosts, staff controls, eligibility checks, or private channel access.
  • Invite, join, leave, nickname, or server event details when used by Mafia staff safety or review tools.

Mafia Feature Data

  • Game setup, host information, joined players, assigned roles, alive or eliminated status, team or alignment data, and game outcomes.
  • Votes, night actions, private chat or channel IDs, logs, moderation notes, warnings, mutes, points, host stats, and game statistics.
  • Server configuration such as enabled cogs, command settings, staff roles, logging channels, game settings, and FAQ or panel settings.
  • Command usage, timestamps, errors, diagnostics, and limited interaction content needed to process commands, buttons, menus, and modals.

How We Use Information

Operational Use

Information is used to run Mafia games, manage hosts and players, assign or restrict roles, maintain private game spaces, process votes and actions, show results, track optional stats, and save server settings chosen by authorized staff.

Safety And Abuse Prevention

Information may also be used to prevent cheating, command abuse, spam, duplicate actions, moderation evasion, unauthorized access to private Mafia areas, or misuse of server systems.

Discord Gateway Intents

The bot uses Discord gateway intents so Discord can send events needed for commands, Mafia game operation, moderation, staff tools, private channels, logs, role checks, and support workflows.

Message Content Intent

Used when message text is needed for prefix commands, host commands, Mafia game log parsing, private chat workflows, moderation tools, staff notes, FAQ responses, and other chat-based Mafia features.

Server Members Intent

Used to read member information needed for role checks, host permissions, private game access, mutes, warnings, nickname enforcement, participation tracking, staff review, and member support.

Default Discord Events

Used for normal server operation, such as knowing which servers, channels, threads, roles, messages, reactions, voice states, invites, emojis, and interactions exist where the bot has permission. These events support commands, panels, logs, reactions, and Mafia automation.

Feature And Cog Examples

Known Mafia-related examples from the previous bot include:

  • Mafia panel and command tools (cogs.mafiapanel, cogs.mafiacommands, cogs.mafiaauto, and cogs.mafiafaqpanel) process command metadata, interactions, roles, channels, threads, messages, and game configuration for Mafia setup and operation.
  • Mafia private spaces (cogs.mafia_private_chats) process member, role, channel, thread, and message information to create or manage private Mafia chats or channels.
  • Mafia host, points, and records (cogs.mafia_host_tracking, cogs.mafia_points, and cogs.maulmafia) process game participation, host records, point totals, game results, and related statistics.
  • Mafia moderation and staff safety (cogs.mafia_mutes, cogs.mafia_warnings, cogs.maulnotes, cogs.ncic, cogs.punishments, cogs.warn, cogs.banemoji, cogs.skull_ban, and cogs.rename) process member, role, invite, reaction, nickname, thread, and message data for safety, logs, notes, warnings, mutes, punishments, and staff review.

Message Content

Why Message Content Is Used

The bot may read message content in server channels where it has access when message content is required for enabled Mafia features. This includes prefix commands, host commands, Mafia logs, vote or action parsing, private game chat workflows, staff notes, and chat-based moderation.

Limits

Message content is used for bot functionality only. It is not sold, used for advertising, or shared with unrelated third parties. The bot is not intended to monitor or store unrelated server conversations.

Storage And Access

Where Data Is Stored

Bot data may be stored in local databases, configuration files, logs, or other storage used to operate the bot. Stored data may include Mafia game records, points, host records, moderation records, server settings, warnings, mutes, staff notes, and user opt-in or participation data.

Who Can Access It

Access is limited to authorized server staff, bot maintainers, or administrators who need the information to operate, moderate, troubleshoot, or maintain the bot and server.

Retention And Deletion

Retention

Active Mafia game data is kept as long as needed to run the game and clean up after it ends. Server configuration, optional stats, game history, moderation history, audit logs, and abuse-prevention records may be kept while needed for server administration or safety.

Deletion Requests

Users may request deletion of eligible stored data. Server owners or authorized administrators may request deletion of server-linked configuration or records. Some data may be retained when needed for moderation history, safety, unresolved disputes, audit logs, or abuse prevention.

Sharing

No Sale Of Data

We do not sell user data. We do not share collected data with advertisers or unrelated third parties.

Normal Server Visibility

Some bot output may be visible in server channels as part of normal functionality, such as game signups, host panels, results, logs, public stats, warnings, point totals, or participation information.
